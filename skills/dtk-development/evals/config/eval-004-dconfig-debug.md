# DConfig 调试

## 任务

调试应用配置问题，要求：
1. 查看当前配置值
2. 检查配置文件路径
3. 热加载配置

## 期望输出

代码应：
1. 使用 dde-dconfig 命令查看配置
2. 检查配置文件路径
3. 使用 DCONFIG_DEBUG 环境变量调试
4. 未使用 QSettings 替代 DConfig
5. 配置服务不可用时未阻塞主窗口（应有 fallback）
6. 未混淆 appId 与配置 ID

## 验证要点

- [ ] 使用 dde-dconfig 命令查看配置
- [ ] 检查配置文件路径
- [ ] 使用 DCONFIG_DEBUG 环境变量调试

## 评分标准

| 等级 | 条件 |
|------|------|
| ✅ **PASS** | 所有验证要点全部满足，代码可编译或语法正确 |
| ⚠️ **PARTIAL** | 核心功能满足（第 1-2 项），但边缘检查项未通过 |
| ❌ **FAIL** | 核心功能未实现，或使用了禁止的模式

## 反模式检查

- [ ] 未使用 QSettings 替代 DConfig
- [ ] 配置服务不可用时未阻塞主窗口（应有 fallback）
- [ ] 未混淆 appId 与配置 ID
