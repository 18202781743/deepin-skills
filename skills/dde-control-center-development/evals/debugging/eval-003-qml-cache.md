# Eval: QML 修改不生效问题排查

## 任务

用户修改了插件 QML 文件后重新编译，但运行时修改不生效。帮助用户排查问题。

## 期望输出

回答应：
1. 列出常见原因（文件名规范、缓存问题）
2. 给出清除 QML 缓存的命令
3. 说明 QML 文件名规范要求

## 验证要点

- [ ] 提到 QML 文件名必须首字母大写
- [ ] 提到不能使用 `main.qml`（已废弃）
- [ ] 给出清除缓存命令：`rm -rf ~/.cache/dde-control-center/qmlcache/`
- [ ] 提到需要重新编译 QML 模块

## 评分标准

| 等级 | 条件 |
|------|------|
| ✅ **PASS** | 所有验证要点全部满足，代码可编译或语法正确 |
| ⚠️ **PARTIAL** | 核心功能满足（第 1-2 项），但边缘检查项未通过 |
| ❌ **FAIL** | 核心功能未实现，或使用了禁止的模式

## 反模式检查
- [ ] 未直接修改系统安装文件
- [ ] 排查时先确认 --spec 或环境变量指向正确产物
